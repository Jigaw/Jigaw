# ARJUN

An interactive 3D "ARJUN" built from blocks, in a single self-contained web page (three.js, no build step).

Open `index.html` in a modern browser. Everything it needs is inside the file except three.js and fonts, which load from public CDNs.

## Themes

Pick a theme from the dropdown in the bottom-right corner:

- **Snow**: packed snow blocks in a wind-blown snowstorm, on a snow floor you can plough through with the pointer.
- **Stone**: weathered sandstone blocks with carved hieroglyphs, in a desert with pyramids, a temple and palms.
- **Water**: clear water blocks with caustics and bubbles, over a flooded desert.
- **Fire**: molten blocks with flames, plus lava stones that jump out of their holes (hover one to hold it up on a jet of steam).
- **Electric**: blue crystal blocks with lightning crackling over them, under a storm.

## Interaction

- Move the pointer over the word to push blocks out of the wall; an automatic shock wave sweeps across when you are not hovering.
- Drag to orbit the camera, scroll or pinch to zoom.
- **SOUND** turns on the music and sound effects for the current theme.

Works on desktop and on phones (lighter rendering and adaptive resolution on mobile).
